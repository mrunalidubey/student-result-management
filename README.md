# Student Result Management System

A Python + SQLite project to manage student results.

## Features
- Add/Delete Students
- Add Subjects and Results
- Auto Pass/Fail Detection
- Top 3 Students
- Average Marks Per Branch

## Tech Stack
- Python
- SQLite
- SQL (JOINs, GROUP BY, HAVING, CASE WHEN)

## How to Run
```
python3 main.py
```
